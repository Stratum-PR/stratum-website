# FDA data for Puerto Rico food firms (`/inspecciones-fda-puerto-rico`)

Numbers on the page live in `src/content/fda-inspections-pr.ts`. This folder holds the pulled
data and the scripts that regenerate them. Aggregates only: no firm names, FEI numbers or
addresses are stored here or shown on the page.

Last pulled: **2026-11-11**.

## Files

| File | What |
| --- | --- |
| `inspections-pr-food-by-fy.csv` | Food inspections in PR per FDA fiscal year, by final classification |
| `citations-pr-food-top-fy2022-2026.csv` | Most-cited sections in PR food inspections, FY2022–FY2026 |
| `openfda-food-enforcement-pr.json` | openFDA food enforcement records for `state:"PR"` (non-identifying fields only) |
| `openfda-recalls-pr-by-year.csv` | Recall events and recalled products by class, per calendar year of initiation |
| `dashboard-console-snippet.js` | Regenerates the two inspection CSVs from the FDA Data Dashboard |
| `compute-openfda-recalls.mjs` | Regenerates the recall aggregates from openFDA |

## 1. Inspections and citations: FDA Data Dashboard

- Page: https://datadashboard.fda.gov/oii/cd/inspections.htm (public, no login)
- The Dashboard's REST API (`api-datadashboard.fda.gov/v1/inspections_classifications`,
  `/inspections_citations`) requires registered credentials (Authorization-User / Authorization-Key
  from the OII Unified Logon). **We did not use it.**
- The "Entire Inspections/Citations Dataset" download links are generated by the page's Qlik app
  (no static file URL), so the snippet queries that same public app from the browser console.

To refresh: open the page, wait for the charts, paste `dashboard-console-snippet.js` into the
console, then copy the printed JSON into the CSVs and into `fda-inspections-pr.ts`.

Method:
- Filter: `Inspection State Code = PR`, `Product Type = Food/Cosmetics`.
- The source has one row per inspected *project area*. Rows for "Colors and Cosmetics Technology"
  are dropped; inspections with no remaining food project area are excluded (16 at pull time).
- Each inspection counts once, in its FDA fiscal year (Oct 1 – Sep 30), with its most serious
  food classification (OAI > VAI > NAI). FDA's own charts count classifications per project area,
  so their totals can be higher.
- Citations: `Program Area = Foods`, state PR, restricted to the food inspections above in
  FY2022–FY2026. A CFR section counts once per inspection that cited it (several FDA citation
  codes can share one section, e.g. 21 CFR 117.135(a)(1) has 8).
- Caveats (from the Dashboard page): only final classifications; updated weekly; state contract
  inspections are not included; citations from manually prepared 483s do not appear in the
  citations data. Recent fiscal years can still grow as classifications are finalized. FY2027
  (3 inspections at pull time) is incomplete and not shown.

Results at pull time (FY2022–FY2026): 447 food inspections; NAI 194, VAI 235, OAI 18;
228 of them have citations in the citations dataset.

## 2. Recalls: openFDA food enforcement

- `https://api.fda.gov/food/enforcement.json?search=state:"PR"&limit=1000` (public, no key)
- `state` is the recalling firm's state. One record = one recalled product (`recall_number`);
  one recall event (`event_id`) can cover several products.
- Year = calendar year of `recall_initiation_date`. openFDA enforcement data starts in 2012.
- At pull time: 230 products in 85 events, openFDA `last_updated` 2026-11-04.

```
node scripts/data/fda-pr/compute-openfda-recalls.mjs --fetch
```

## Not used

- FDA warning letters (fda.gov listing): the listing has no state/location field, so letters to
  PR firms can't be counted without opening each letter. Left as a TODO on the page.
